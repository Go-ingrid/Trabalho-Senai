 Site Trancista

Projeto desenvolvido para o trabalho do SENAI, com o objetivo de criar um site para divulgação de serviços de trancista.

## 📌 Sobre o projeto

O site apresenta informações e serviços relacionados ao trabalho de trancista, utilizando uma interface simples e intuitiva.

 🛠️ Tecnologias

* HTML
* CSS
* JavaScript

 🚀 Como executar

1. Clone este repositório:

bash
git clone https://github.com/Go-ingrid/Trabalho-Senai.git
```

2. Abra a pasta do projeto.
3. Execute o arquivo principal no navegador.
